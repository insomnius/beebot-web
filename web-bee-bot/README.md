# Web Bee-Bot 🐝

A modern, browser-based version of the beloved Bee-Bot robot designed to teach children aged 4-8 the fundamentals of programming and computational thinking.

## 🌟 Features

- **Interactive Grid Environment**: 6x6 learning mats with various themes (alphabet, numbers, community, shapes)
- **Simple Command Interface**: Drag-and-drop or tap-button UI for programming commands
- **Step-by-Step Visual Feedback**: Animated Bee-Bot movement with clear visual cues
- **Multiple Learning Mats**: Different difficulty levels and educational themes
- **Progress Tracking**: Score system, levels, and achievement badges
- **Kid-Friendly Design**: Colorful interface with large buttons and engaging animations
- **Responsive Design**: Works on desktop, tablet, and mobile devices

## 🚀 Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd web-bee-bot
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎮 How to Play

1. **Choose a Learning Mat**: Select from different themes like alphabet, numbers, or community
2. **Program Bee-Bot**: Use the command buttons to create a sequence of instructions
3. **Execute Commands**: Press "Go Bee-Bot!" to watch your program run
4. **Reach the Target**: Guide Bee-Bot to the target position using your commands
5. **Debug and Improve**: If Bee-Bot doesn't reach the target, modify your program and try again!

### Available Commands

- **⬆️ Forward**: Move Bee-Bot one square in the current direction
- **⬇️ Backward**: Move Bee-Bot one square opposite to the current direction
- **⬅️ Turn Left**: Rotate Bee-Bot 90 degrees to the left
- **➡️ Turn Right**: Rotate Bee-Bot 90 degrees to the right
- **⏸️ Pause**: Wait for one step (useful for timing)

## 🏗️ Technology Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom Bee-Bot theme
- **Animations**: Framer Motion for smooth, engaging interactions
- **State Management**: React hooks with TanStack Query for data fetching
- **Icons**: Lucide React for consistent iconography
- **Notifications**: React Hot Toast for user feedback
